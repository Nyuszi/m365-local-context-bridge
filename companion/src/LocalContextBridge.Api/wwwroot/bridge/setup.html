Setup guide
  1. Click Add extension (opens Chrome Extensions + Finder).
  2. If a blocked/disabled “Local Context Bridge” is listed, remove it.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and choose the folder highlighted in Finder.
  5. Come back here and click Refresh status.
